<MfaNote />

## Choose a factor

Pick TOTP, email OTP or passkeys. See the [quick start](../get-started/quick-start.mdx#register-an-application).

:::note
Users enroll their second factor the next time they sign in. MARKER-ADMONITION
:::

<Tabs>
<TabItem value="totp" label="TOTP">
Scan the QR code with an authenticator app. MARKER-TAB-TOTP
</TabItem>
<TabItem value="email" label="Email OTP">
Enter the code sent to your email address. MARKER-TAB-EMAIL
</TabItem>
</Tabs>

<details>
<summary>Why a second factor?</summary>

A stolen password alone can no longer sign in. MARKER-DETAILS

</details>
