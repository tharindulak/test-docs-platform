## Words to avoid

| Word | Why |
|---|---|
| `click here` | Link text says where the link goes. |
| `simply` | Condescending; cut it. |
| `easily` | Condescending; cut it. |
| `obviously` | Condescending; cut it. |
| `please note` | Filler; state the point. |
| `it is important to note that` | Filler; state the point. |
| `leverage` | Use "use". |
| `seamless` | Promotional; describe the behavior. |
| `seamlessly` | Promotional; describe the behavior. |

US English. The spelling check uses the Platform dictionary (`standards/dictionaries/wso2.txt`) plus each Content repository's own `words.txt`, one word per line.
