Use an admonition by meaning, not for variety. Write it with three colons:

```md
:::warning
Rotating the key signs out every user.
:::
```

## Types

| Type | Use it for |
|---|---|
| `note` | A useful aside. |
| `tip` | A better or faster way. |
| `info` | Background or context. |
| `warning` | Could cause errors, security exposure or downtime. |
| `danger` | Irreversible, or risks data loss. |

## Limits

- No more than two admonitions in a row.
- Don't put content that belongs in the main text in an admonition.
- Don't repeat the paragraph above it.

## Migrated admonitions

The migration from MkDocs maps the other admonition types onto these five:

| MkDocs type | Becomes |
|---|---|
| `abstract` | `info` |
| `example` | `note` |
| `important` | `warning` |
| `caution` | `warning` |
| `attention` | `warning` |
| `hint` | `tip` |
| `success` | `tip` |
| `question` | `note` |
| `failure` | `warning` |
| `bug` | `warning` |
| `quote` | `note` |
