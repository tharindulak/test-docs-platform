WSO2 Docs is written in Markdown and MDX, in one GitHub repository per product, and reviewed in pull requests. These pages cover everything you need to change a page or add a new one, whichever product you write for.

## Where to begin

- New here? Follow [Start here](get-started/start-here.mdx). It takes you from your first edit to a merged pull request.
- Looking for a command? See the [cheat sheet](get-started/cheat-sheet.mdx).
- Writing a page? Read the [style guide](reference/style-guide.mdx) and pick a [page type](concepts/page-types.mdx).
- Own a product's docs? Read the [developer guide for product teams](get-started/product-teams.mdx). It explains Doc spaces, the menus, the manifests, the repository layout and releases.
- On the Platform team? Read the [guide for running WSO2 Docs](get-started/platform-team.mdx). It covers the navigation, onboarding teams, the release pipeline, Platform releases, search and extensions.

The standards on these pages are owned by the docs standards owner and a representative from each product's doc team. To propose a change, open a pull request against `standards/` in the `wso2/docs-platform` repository.
