This guide is for the team that owns a product's docs. It explains how WSO2 Docs is put together, and how your team decides where its docs appear. Writers who only change pages need [Start here](start-here.mdx) instead.

The guide uses the Pilot's real Doc spaces as examples: Identity Platform Cloud and Identity Server in `docs-identity-platform`, and API Platform Cloud, API Manager and AI Gateway in `docs-api-platform`.

## Where the guide lives

This guide has one copy: these pages, published at `docs.wso2.com/contribute/`. Their source is in the Platform repository, under `standards/contribute/`. The Platform's README and every Content repository's README link here and don't repeat it. To change the guide, open a pull request against `standards/contribute/` in `wso2/docs-platform`.
