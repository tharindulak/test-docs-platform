This guide is for the Platform team, the team that keeps the Platform and runs WSO2 Docs for every product team. It is the companion of the [developer guide for product teams](product-teams.mdx). That guide explains the model and what a product team does. This one covers what only the Platform team does: the navigation, onboarding, the release pipeline, Platform releases, search and extensions.

Read the developer guide's concepts first. This guide doesn't repeat them.

The guide uses the Pilot's real Doc spaces as examples: Identity Platform Cloud and Identity Server in `docs-identity-platform`, API Platform Cloud, API Manager and AI Gateway in `docs-api-platform`, and the Sandbox in `docs-sandbox`. Every command on these pages is the one the workflows run, and each how-to says whether it can be rehearsed on your own computer.

## Hosting values

WSO2 Docs isn't hosted yet. Where a page needs a hosting value, it shows a placeholder, such as `<staging-host>`. [Secrets, variables and hosting values](../reference/platform-team/secrets-and-variables.mdx#hosting-values) lists each placeholder, the value the code assumes for now, and where to change it. The Cloudflare deploy runbook fills them in.
