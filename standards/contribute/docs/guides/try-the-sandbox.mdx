The `wso2/docs-sandbox` repository is a small Doc space for practice. It has a few dozen pages across two Editions, with real Edition markers and partials. It's published on staging only and reset every month.

## Prerequisites

- A GitHub account with access to `wso2/docs-sandbox`.

## Practice the flow

1. Make a [quick edit](quick-edit.mdx) to any page.
2. Clone the repository and make a local change: [create a page](create-a-page.mdx), or add an Edition marker.
3. [Check your changes](check-your-changes.mdx) and [open a pull request](open-a-pull-request.mdx).
4. After the merge, [backport the fix](backport-a-fix.mdx) to its `release/1.0.0` branch.

## Verify

Your change appears in the Sandbox Doc space on staging.
