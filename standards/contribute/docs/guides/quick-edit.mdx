Fix a typo, a sentence or a broken step directly on GitHub. The same checks and preview run as for a local change.

## Prerequisites

- A GitHub account.

## Edit the page

1. On the page you want to fix, select **Edit this page**. The file opens in GitHub on the `main` branch, because fixes go to the newest docs first.
2. Make your change. Keep the front matter between the `---` lines as it is.
3. Select **Commit changes**, choose **Create a new branch** and select **Propose changes**.
4. Select **Create pull request**.

To change several files at once, press the `.` key on the repository page to open github.dev, an editor in your browser.

## Verify

After about 5 to 10 minutes, the pull request shows the checks and a link to a preview of your change. Open the preview and find your page. See [Open a pull request](open-a-pull-request.mdx) for what to do if a check fails.
