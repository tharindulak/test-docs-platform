A Docs section manifest decides three things for each Doc space: its entry in the products menu, its line in the section's menu, and where its version is chosen. Change them with a pull request to the Platform repository.

## Prerequisites

- Your Doc space manifest is on your Content repository's `main`. See [Write your Doc space manifest](write-the-manifest.mdx).
- You keep the section's manifest, `navigation/sections/<id>.yaml` in `wso2/docs-platform`, or you ask the team that does. `.github/CODEOWNERS` names each section's team.

This is the API Platform section manifest:

```yaml
schemaVersion: 1
id: api-platform
title: API Platform Documentation
owners:
  team: api-platform-docs
products:
  - label: API Manager
    opens: { docSpace: api-manager }
  - label: AI Gateway
    opens: { docSpace: ai-gateway }
  - label: Monetization
    opens: { docSpace: api-platform, page: guides/monetization/ }
menu:
  - docSpace: api-platform
    version-in: header
  - docSpace: api-manager
    version-in: menu
  - docSpace: ai-gateway
    version-in: menu
```

## Add the products-menu entry

1. Under `products`, add an entry in the order wso2.com's header lists the family's products.
2. Set `label` to the product's name exactly as wso2.com writes it.
3. Set `opens`:
   - `docSpace` alone opens the Doc space where its version selector opens: Cloud where it has Cloud, else its newest release. A component's Cloud part counts once its platform's Cloud tree is deployed;
   - add `edition` to open one Edition;
   - add `page` to open one page, such as `guides/monetization/`, for a product with no Doc space of its own yet.

The family's Cloud needs no entry: the products menu lists it first in the group, from the section's menu. Products not on WSO2 Docs yet are listed from the Platform navigation file, with their old site.

## Add the menu entry

1. Under `menu`, add the Doc space with `docSpace: <slug>`. The family Cloud comes first, then the products.
2. To link out of WSO2 Docs, add a link entry with a `label` and a `url`. It shows with ↗:

   ```yaml
   menu:
     - docSpace: integration-platform
     - label: Ballerina
       url: https://ballerina.io/learn/
   ```

   A link entry can't point into WSO2 Docs. List that Doc space as an entry instead.

3. To borrow a Doc space whose home is another section, list it in your menu like your own. Its team is told in the compose report, and its home section doesn't change.

## Choose where the version is chosen

Set `version-in` on each Doc space entry:

| Value | Effect | Use it for |
|---|---|---|
| `header` | The Edition is chosen only in the header selector | A Doc space with one Edition, such as a family Cloud |
| `menu` | The entry also gets its own dropdown on its line, in step with the header | Products with several Editions, such as API Manager and AI Gateway |

Leave it out to get the default: `menu` for two or more Editions, else `header`. A Cloud part counts as one Edition, so Identity Server has three. `version-in: menu` on a Doc space with one Edition is an error.

## Verify

1. Open the pull request. The **Compose check** runs against the latest merged manifest and lists every error with its file and owner.
2. After the merge, the change reaches every page with the next published manifest. Open a page in the section and check the menu. No rebuild is needed.

## Troubleshooting

| Error or warning | Fix |
|---|---|
| `unknown-docspace` (warning) | The slug isn't a Doc space yet. The entry stays hidden until that Doc space is published, so merge this change first. If the slug is wrong, fix it. |
| `lists-unlisted` | The Doc space is Unlisted (`listed: false`). No section may list it. |
| `version-in` | `version-in: menu` needs two or more Editions. |
| `link-internal` | A link entry points into WSO2 Docs. List the Doc space instead. |
| `label-differs` (warning) | The products-menu label differs from the Doc space's name. Check it matches wso2.com. |
| `borrowed-not-in-home-products` (warning) | A borrowed Doc space is missing from its home section's products. Ask the home section's team to add it. |
