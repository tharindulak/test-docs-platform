Turn on notifications for a project, so that you hear about changes to it.

## Prerequisites

<BeforeYouStart />

## Turn on notifications

1. Open the project and select **Settings**.
2. Turn on **Notifications**.
3. Select **Save**.

<Edition only="cloud">
In Cloud, notifications go to the email address of your account.
</Edition>

<Edition only="self-hosted">
On your own installation, set the mail server first in [the configuration](../reference/configuration.mdx).
</Edition>

## Verify

The project's **Settings** page shows **Notifications: On**.
